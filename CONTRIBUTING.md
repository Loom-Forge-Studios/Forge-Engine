# Contributing

**Pull requests are not currently accepted.**

Forge Engine is commercial and source-available (see [README](README.md#licensing)).
Until the licence agreement and a contributor licence agreement are published, there is no
mechanism by which a contributor can grant this project the rights it needs to include
their work in a product that is sold. Merging a contribution before that exists creates a
rights problem that is expensive, and sometimes impossible, to unwind later.

This is a legal constraint, not a judgement about contributions. A CLA will be published
alongside the licence agreement.

## What is welcome now

- **Issues** — bugs, design questions, and gaps in the [engineering plan](docs/plan/).
- **Discussion** — the plan is public specifically so it can be argued with. If a decision
  in [`docs/plan/decisions.md`](docs/plan/decisions.md) looks wrong, say so, and cite what
  it missed.

## If you are reading the plan

Start with [`docs/plan/master-plan.md`](docs/plan/master-plan.md). Its *Reality check* and
*Working agreements* sections are binding and explain how the rest is meant to be read.
